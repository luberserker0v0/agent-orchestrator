# Developer Prerequisites

Requirements for contributing to AgentOrchestrator development.

## Required

| Requirement | Version | Purpose |
|-------------|---------|---------|
| **Node.js** | >= 24.0.0 | Runtime |
| **npm** | >= 10.0.0 | Package manager |
| **Git** | >= 2.30 | Version control |

## Optional

| Requirement | Version | Purpose |
|-------------|---------|---------|
| **Docker** | >= 20.10 | E2E testing with Docker runtime |
| **OpenCode CLI** | >= 1.17.0 | E2E testing with direct runtime |
| **VS Code** | Latest | Recommended IDE |

## Recommended VS Code Extensions

| Extension | Purpose |
|-----------|---------|
| ESLint | Code linting |
| Prettier | Code formatting |
| Vitest | Test runner |
| GitLens | Git integration |

## Verifying Installation

```bash
node --version   # >= 24.0.0
npm --version    # >= 10.0.0
git --version    # >= 2.30
docker --version # >= 20.10 (optional)
```
