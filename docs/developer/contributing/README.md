# Contributing

Thank you for your interest in contributing to AgentOrchestrator!

## Quick Start

1. Fork the repository
2. Clone your fork
3. Create a feature branch
4. Make your changes
5. Run `npm run preflight`
6. Push and create a Pull Request

See [Workflow](workflow.md) for detailed steps.
